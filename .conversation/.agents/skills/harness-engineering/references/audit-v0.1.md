# v0.1.0 生产级适用性审查

日期：2026-09-23。范围：Skill 文档与模板静态审查，不是运行系统审计。
结论：v0.1 不满足生产级 Harness 构建规范要求；具备基础原则，但生产控制不完整。

## 主要问题

| 严重度 | 缺口 | v0.2 修订 |
| --- | --- | --- |
| 发布阻断 | 主定位偏开发流程，没有生产服务范围、SLO 和风险分级 | 主 Skill 第0步、G01、PRR |
| 发布阻断 | 权限描述不足以覆盖审批过期、撤销、参数变更和子 Agent 委托 | G02 |
| 发布阻断 | 检查点/幂等缺少多 worker、租约失效、乱序投递等明确语义 | G03/G04 |
| 发布阻断 | 缺少错误预算、准入背压、租户公平性与并发成本预留 | G05 |
| 发布阻断 | 记忆投毒、缓存隔离与压缩后权限保真未形成控制要求 | G06 |
| 发布阻断 | 没有灾难恢复演练、删除后恢复防复活、数据迁移兼容门槛 | G07 |
| 发布阻断 | 有日志字段但没有告警 owner、升级路径、停用开关和审计失效策略 | G08 |
| 发布阻断 | 场景清单不等于执行证据，缺少独立生产就绪判定 | G09、PRR |
| 发布阻断 | 缺少灰度标准、在途版本固定、真实回退验证 | G10 |
| 重要 | 项目适配容易把“MVP 简化”误解成降低运行控制要求 | 主 Skill 明确控制目标不降级 |

“发布阻断”指该缺口若存在于待上线系统，应阻断上线；不是声称已有线上漏洞。
原有优点保留：五要素、有限重试、未知写结果核对、隐私日志、反自改裁判。

## 验证边界

v0.2 只是提升规范覆盖范围，不能证明 Agent 能持续遵循规范。
仍需要：独立 Skill 行为评估、实现级集成测试、故障注入、压测、恢复与灰度演练。
新的测试设计和文档静态检查不能记为这些验证已通过。
